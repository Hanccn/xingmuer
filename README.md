# 行木儿

> 出发前的准备，从这里开始就够了。

帮你把收藏的景点变成一条能导出到手机的路线。填补「小红书种草」和「携程下单」之间的决策辅助层。

🔗 在线原型：[hanccn.github.io/xingmuer](https://hanccn.github.io/xingmuer/)

---

## 为什么做这个

自由行用户出发前要横跳 6-8 个 App：小红书查攻略 → 携程看酒店 → 高德查距离 → 马蜂窝看点评 → 微信问朋友 → 备忘录写行程。

最关键的三个决策——**住哪里、怎么走、先去哪**——反而没人帮。行木儿只解决这一件事。

---

## 核心差异化

- **选址推荐** — 基于收藏景点分布 + 实时路况，自动推荐最省交通时间的住宿区域
- **80 字 Tips** — 不写长篇游记，像朋友发微信一样一句话说清楚"值不值得去"
- **弹性路线** — 紧凑型按分钟排、弹性型只分天，两种节奏自由切换
- **Agent 搜索** — 输入"周末两天上海周边适合爬山"，AI 拆分约束匹配目的地

## 原型

8 页 HTML 原型，全链路导航互通，覆盖从「搜目的地」到「导出到手机」的完整旅程。

在线体验：[hanccn.github.io/xingmuer](https://hanccn.github.io/xingmuer/)

---

## 技术选型

Django + 原生 HTML/CSS/JS + 高德 JS API + DeepSeek API，部署在 Railway + GitHub Pages。

选择 Django 而非 Next.js 是权衡：项目周期短、以内容驱动为主、高德 API 调用多为服务端 → Python 生态更高效。原型用原生 HTML 而非 Vue/React，因为目标是快速验证交互流程而非搭建组件库。

## 原型页面

| 页面 | 说明 |
|------|------|
| 首页 | 城市搜索 + Agent 自然语言搜索 |
| 发现页 | 分类入口 + 热门目的地 + 省份维度 |
| 城市列表 | 景点列表 + 地图视图切换 |
| 景点详情 | 基础信息 + Tips + 收藏 |
| 主题灵感 | 按主题聚合景点（如老茶馆地图） |
| 我的规划 | 收藏列表 + 选址推荐 + 路线生成 |
| 路线结果 | 按天拆分 + 地图预览 + 分享导出 |
| 我的行程 | 历史行程列表 + 分享码访问 |
